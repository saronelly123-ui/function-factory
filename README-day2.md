# Day 2: Logic Practice

## Project Overview
This project contains 10 JavaScript logic practice problems and one additional challenge. The goal is to practice pseudocode, conditional statements, loops, arrays, and logical operators.

## Technologies Used
- JavaScript
- Node.js
- Visual Studio Code

## Problems Covered
1. Even or Odd Number
2. Grade Calculator with Input Validation
3. Ticket Price Calculator
4. Day Planner Using Switch
5. Countdown from 10 to 1
6. Sum and Average Using `for...of`
7. Find the First Number Greater Than 100 Using `break`
8. Skip Negative Numbers Using `continue`
9. Multiplication Table of 7
10. FizzBuzz with the Additional Rule for "Kigali"

### Bonus Challenge
- Print a right-angled triangle of stars using nested loops.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Run the following command:

```bash
node day2.js
```

4. Check the output in the terminal.

## What I Learned
- Writing pseudocode before coding.
- Using `if`, `else if`, and `else`.
- Using `switch` statements.
- Working with `for` and `for...of` loops.
- Using `break` and `continue`.
- Calculating sums and averages.
- Validating input using guard clauses.
- Using nested loops to create patterns.
